# Python Beginner Projects

A collection of beginner Python projects created while learning Python programming.

These projects focus on fundamental Python concepts such as variables, loops, conditionals, user input, exception handling, and working with modules.

## Prerequisites

Make sure Python is installed on your computer.

Check your Python version:

```bash
python --version
```

or

```bash
python3 --version
```

## Installing Python

Download and install Python from:

https://www.python.org/downloads/

During installation on Windows, ensure that **"Add Python to PATH"** is checked.

## Clone the Repository

```bash
git clone https://github.com/your-username/python-beginner-projects.git
```

Navigate to the project directory:

```bash
cd python-beginner-projects
```

## Projects

### Number Guessing Game

A game where the user tries to guess a randomly generated number between 1 and 100.

**Concepts Used**
- Variables
- Loops
- Conditionals
- Exception Handling
- Random Module
- User Input

Run:

```bash
python number_guessing_game.py
```

### Dice Roller

A simple dice rolling simulator that rolls two dice a specified number of times.

**Concepts Used**
- Loops
- Conditionals
- Random Module
- User Input
- String Formatting

Run:

```bash
python dice_roller.py
```
